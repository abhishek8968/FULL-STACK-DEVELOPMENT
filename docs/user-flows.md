# Core User Flows

## Adopter
1. Sign up (email or Google).
2. Complete profile: living type + pet experience.
3. Browse `/pets` and apply filters.
4. Open pet profile and submit adoption request.
5. Start in-platform chat after owner/shelter review.
6. Arrange meet-and-greet and finalize adoption.

## Pet Owner
1. Register and verify contact details.
2. Create pet listing with health, temperament, reason for rehoming.
3. Wait for admin moderation approval.
4. Receive and review adoption requests.
5. Message selected adopters and finalize handover.

## Shelter/Rescue
1. Create organization profile and verification request.
2. Publish multiple listings.
3. Manage requests and chats from dashboard.

## Admin/Moderator
1. Review new listings.
2. Reject suspicious posts and enforce no-sales policy.
3. Verify users/organizations.
4. Monitor reports and platform adoption activity.
