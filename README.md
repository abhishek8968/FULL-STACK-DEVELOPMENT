# Pet Haven UAE

Production-ready website scaffold for a UAE pet adoption and rehoming marketplace built with Next.js, TailwindCSS, and Supabase-ready APIs.

## MVP included
- Homepage with hero, featured pets, success/flow messaging, partner shelters, and policy statement.
- Discovery marketplace and SEO-friendly pet detail pages.
- Rehome listing form and moderation-first flow.
- Resource hub, veterinary directory, and admin moderation page.
- API route handlers for pets, adoption requests, messages, and moderation.
- PostgreSQL schema and architecture documentation in `/docs`.

## Run locally
```bash
npm install
npm run dev
```
